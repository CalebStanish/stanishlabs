# Stanish Labs

Public homepage for Stanish Labs, with company information, services, selected work, and contact options.

## Development

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. Output is written to `dist/`.

## Before publishing

- Confirm the service descriptions and company positioning.
- Replace the selected-work placeholder with approved case studies.
- Confirm that `hello@stanishlabs.com` is the correct customer contact address.

# Docker hosting

Run `docker compose up -d --build` to serve the site persistently at `http://10.10.20.102:18092`.
